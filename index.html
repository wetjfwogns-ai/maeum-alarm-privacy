마음 알람 개인정보처리방침

시행일: 2026년 10월 4일

「마음 알람」(이하 앱)은 내가 녹음한 목소리와 적어 둔 글을 정한 시간에 들려주는 알람 앱입니다. 앱은 어떤 개인정보도 수집하거나 외부로 보내지 않습니다.

1. 앱이 다루는 정보

  • 녹음한 소리 — 사용자가 녹음 버튼을 누른 동안만 마이크로 녹음합니다.
  • 적어 둔 글 · 알람 이름 · 시간 · 폴더 — 사용자가 직접 입력한 내용입니다.

이 정보는 모두 사용자의 휴대전화 안(앱 전용 저장공간)에만 저장됩니다. 개발자의 서버나 다른 회사로 전송되지 않으며, 개발자도 볼 수 없습니다.

2. 권한을 쓰는 이유

  • 마이크 — 알람으로 들을 내 목소리를 녹음하기 위해.
  • 알림 · 전체 화면 알림 — 알람이 울릴 때 잠금화면 위로 「끄기」 화면을 띄우기 위해.
  • 정확한 알람 — 사용자가 정한 시각에 정확히 울리기 위해.
  • 부팅 완료 알림 받기 — 휴대전화를 다시 켠 뒤에도 맞춰 둔 알람을 되살리기 위해.

3. 광고 · 분석 · 제3자 제공

앱에는 광고, 사용 기록 분석 도구, 로그인 기능이 없습니다. 정보를 제3자에게 제공하지 않습니다.

4. 보관과 삭제

녹음과 글은 사용자가 앱에서 지우거나, 앱을 삭제하면 휴대전화에서 함께 지워집니다. 휴대전화의 구글 백업을 켜 두었다면 안드로이드가 앱 데이터를 사용자 본인의 구글 계정에 백업할 수 있으며, 이는 구글의 백업 정책을 따릅니다.

5. 아동

앱은 아동을 대상으로 하지 않으며, 아동의 정보를 따로 수집하지 않습니다.
